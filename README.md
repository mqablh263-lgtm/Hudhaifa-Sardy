# سجل متابعة الطالب حذيفة السردي

سجل إلكتروني بسيط لمتابعة تسميع الطالب **حذيفة السردي** في الحفظ والمراجعة.

## المزايا
- 📊 إحصائيات تتحدث تلقائيًا: لقاءات الحفظ والمراجعة، إجمالي مرات التسميع، إجمالي الصفحات، صفحات الحفظ، صفحات المراجعة، آخر تاريخ تسميع.
- 🏆 آخر 3 إنجازات.
- 📅 جدول التسميع الأسبوعي (الأحد والخميس).
- 📖 سجل إنجازات الحفظ و 🔄 سجل إنجازات المراجعة في جدولين منفصلين، مع تعديل وحذف.
- ➕ نموذج لإضافة إنجاز جديد بعد كل لقاء.
- 💾 حفظ تلقائي في المتصفح (localStorage)، مع تنزيل واستعادة نسخة احتياطية (JSON).
- 🖨️ طباعة تقرير A4 مرتب.

## التشغيل
افتح `index.html` مباشرة في المتصفح، ولا يحتاج الموقع إلى أي خادم أو تثبيت.

## النشر على GitHub Pages
1. ارفع الملفات إلى مستودع على GitHub.
2. افتح **Settings ← Pages**.
3. في **Source** اختر الفرع `main` والمجلد `/ (root)`، ثم احفظ.
4. سيظهر رابط الموقع بعد دقيقة تقريبًا.

## ملاحظة مهمة عن البيانات
البيانات تُحفظ داخل المتصفح الذي تستخدمه، وليس على GitHub. لذلك:
- البيانات التي أضفتها على نسخة الملف في جهازك لا تنتقل تلقائيًا إلى رابط GitHub Pages. انقلها بزر **⬇️ تنزيل نسخة احتياطية** ثم **⬆️ استعادة نسخة** في الموقع الجديد.
- مسح بيانات المتصفح يحذف الإنجازات، فاحرص على تنزيل نسخة احتياطية بانتظام.
